Approach
--------
All models were evaluated on the same stratified train/test split.
Numeric features were standardized with StandardScaler.
Categorical features were encoded with OneHotEncoder(handle_unknown='ignore').
Each model was wrapped in a single pipeline so preprocessing is saved together with the classifier.

Justification
-------------
Gradient Boosting was selected because it achieved the highest ROC-AUC, with F1-score used as the secondary decision metric. ROC-AUC is useful for churn prediction because it measures how well the model separates churn and non-churn customers across thresholds. F1-score is also important because the churn class is less frequent, so accuracy alone can be misleading.
The runner-up was Logistic Regression with ROC-AUC 0.8419 and F1-score 0.6040.
